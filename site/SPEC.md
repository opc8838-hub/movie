# B2W 官网规范

给所有改这个网站的人和 AI 看。动手前读完。**设计部分写死的数值不准改；觉得不对就停下来问主理人，不要自己“优化”。**

---

## 1. 设计原则

**全站只有黑、白、灰。颜色只来自作品本身。**

界面退到后面，作品站出来。判断一个改动对不对，问这四句：

1. 它是不是在和作品抢眼睛？是就删
2. 删掉它，页面会更差吗？不会就删
3. 手机上还看得清吗？
4. 这句话换个工作室也能用吗？能用就是口号，重写

## 2. 颜色

| 用途 | 值 | CSS 变量 |
|---|---|---|
| 黑 | `#000` | `--black` |
| 白 | `#fff` | `--white` |
| 白底上的次要字 | `#5c5c5c` | `--mute-on-white` |
| 黑底上的次要字 | `#a8a8a8` | `--mute-on-black` |
| 白底上的细线 | `#d6d6d6` | `--line-on-white` |
| 黑底上的细线 | `#333` | `--line-on-black` |
| 行内代码底色 | `#f2f2f2` | `--sunk` |

硬规矩：

- **不准出现任何彩色**：链接、按钮、标签、悬停、焦点框都不行
- **不准给作品调色**：封面和视频不加滤镜、不转黑白、不压暗、不叠蒙层
- 不用渐变、阴影、圆角、毛玻璃、发光
- 不新增灰色，只用上表的值

## 4. 布局

| 项 | 值 |
|---|---|
| 页面左右边距 | `clamp(16px, 3.2vw, 48px)`，变量 `--gutter` |
| 段落上下间距 | `clamp(56px, 8vw, 112px)` |
| 顶栏高度 | 56px，全站黑底，吸顶 |
| 作品网格 | 宽屏 3 列；1000px 以下 2 列；480px 以下 1 列 |
| 手册正文最大宽度 | 52rem |

- 黑白段落交替，靠色块分区，不加边框和卡片底色
- 分隔只用 1px 细线
- 任何宽度都不能出现横向滚动，表格自己在容器里滚

## 5. Logo

| 文件 | 用途 |
|---|---|
| `assets/logo-write-dark.mp4` | 首页开场：黑底白字手写 |
| `assets/logo-write-light.mp4` | 页脚：白底黑字手写 |
| `assets/logo-white.png`、`logo-black.png` | 完整静态 logo，透明底 |
| `assets/mark-white.png`、`mark-black.png` | B2W 方块字，用于顶栏 |
| `assets/favicon.png` | 网页图标 |

- 只用黑或白。不改色、不拉伸、不加描边和投影
- 手写动画每次打开只播一次，不循环
- 开场 logo 居中，四周全黑留白，不在上面叠字
- 手写动画要用 `site/logo_anim.py` 的版本。`b2w-mv1` 里的旧帧切掉了 B 的左下一撇，不要用
- 浏览器不让自动播放，或用户开了“减少动态效果”时，显示静态 logo

## 6. 组件

**作品卡片**：封面 + 标题 + 一行信息（类型、时长、日期）+ 性质标签。

- 封面保持原片比例，不裁切、不加圆角
- 鼠标悬停时淡入 3.5 秒无声预览，循环；移开暂停。触屏不播
- 悬停反馈只有标题下划线和预览，不放大、不上浮

**性质标签**：1px 边框小字，只用这些词：`客户项目`、`合作项目`、`Demo`、`复刻练习`、`自有品牌`、`原创`。不新增，不上色。

**列表行**：标题 + 一句说明 + 箭头。站内链接 `→`，站外链接 `↗`。悬停时箭头右移 6px，标题加下划线。

**筛选**：纯文字，当前项加粗并有 2px 下划线。

**作品页**：黑底播放器在上，白底信息在下，左边标题和规格，右边一句话、怎么做的、学到了什么、注明。视频用浏览器原生控件。

**注明框**：2px 黑边框。全站唯一的粗边框，不要用在别处。

例外：内容里有容易被误解的画面（比如示意证书）时，说明要放在视频上面，片段标题也要直接写明。

---

## 7. 动效

- 只有这几处会动：开场手写、页脚手写、卡片预览淡入（0.18 秒线性）、箭头位移（0.18 秒）
- 不加滚动入场动画、视差、跟随鼠标、页面转场。作品本身就在动，界面不要再抢戏
- 必须支持“减少动态效果”：关掉预览、平滑滚动和手写动画

---

## 8. 文字

- 说具体的事，不写口号。不写“赋能”“打造”“极致”“重新定义”
- 写数字和做法。写“12 版”“56/62 个硬切误差在 35 毫秒内”，不写“精益求精”
- 演示就写演示，占位就写占位。还没做完的如实说
- 每个作品的 `note`（注明）必须写清：是什么性质、参考了谁、音乐和画面来自哪里、哪些是 AI 生成的
- 用了别人音乐的写“版权归原作者，这里仅作学习展示”
- 公开页面不写：报价、客户内部沟通、本机路径、密钥、个人财务

## 9. 作品素材

| 项 | 规格 |
|---|---|
| 正片 | `media/<slug>.mp4`，H.264，CRF 23，最高 4Mbps；长片 CRF 25–27、1.5–3Mbps；单个文件小于 50MB |
| 编码 | `yuv420p`、bt709 标签、`+faststart` |
| 封面 | `media/<slug>.jpg`，横片宽 1000、竖片宽 720 |
| 预览 | `media/<slug>.prev.mp4`，3.5 秒，无声，横片宽 640、竖片宽 400，CRF 30 |

封面选有内容、有主体的一帧，不选黑场、转场中间或闪白。

## 10. 常用操作

文件分工：`site/works.py` 作品资料；`site/style.css` 样式；`site/build.py` 生成页面；`handbook/*.md` 手册正文。**`index.html`、`work/`、`handbook/*.html` 都是生成的，不要手改。**

**加一支作品**：在 `site/transcode.py` 的列表里加上源文件 → 跑 `python -X utf8 site/transcode.py` → 在 `site/works.py` 加一项 → 跑 `python -X utf8 site/make_media.py` → 跑 `python -X utf8 site/build.py`。

**换视频**：替换 `media/<slug>.mp4`，改 `works.py` 里的版本和注明 → 跑 `python -X utf8 site/make_media.py --force` → 跑 build。

**暂时撤下**：在 `works.py` 那一项加 `draft=True`，在 `.gitignore` 加 `media/<slug>*`，跑 build。

**放回连盈**：去掉两项的 `draft=True`，删掉 `.gitignore` 里的 `media/lianying*`，替换视频，跑 make_media 和 build。

**本地预览**：双击 `site/preview.bat`。要用这个，普通服务器不能拖动视频进度。

原有的 `hely-glass/` 和 `jd-lasvegas/guide/` 保持原样，不套新样式。
