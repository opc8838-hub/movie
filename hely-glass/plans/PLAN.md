## 3. Logo 重画成矢量（要干净、通透）

用户原话："一定要抠干净通透"。JPEG 直接抠图一定有毛边、黑边和噪点，**不准直接用位图抠**。做法是重画成 SVG：

1. 原图里分出两部分：左边圆标（白色圆 + 黑色 h + 紫点），右边字标 "hely.fun"（白字 + 紫点）
2. 4 倍 Lanczos 放大后做阈值：白色按亮度（Otsu），紫色按色相。紫色实测中位数约 **#958DED**，在紫点内部取中位数，最后定一个准确值
3. **能用几何的就用几何重建，不要描边描出来**：
   - 外圆：用最小二乘拟合成正圆
   - 两个紫点：拟合成正圆（两个点一样大、一样色）
   - h：竖笔画和右腿是直边矩形，拱形是圆弧；右腿底部是平切，切口在紫点上方。按测出的尺寸用矩形 + 圆弧拼出来
   - 字标 hely.fun：几何无衬线字体。先试着找出最接近的开源字体（Outfit / Lexend / Urbanist / Manrope / Plus Jakarta Sans 等），叠图对比；能对上（IoU ≥ 0.98）就用字体轮廓，对不上就用 potracer 描（alphamax 0.8，opttolerance 0.2），描完把直边拉直
4. 输出到 `assets/logo/`：
   - `mark_on_dark.svg`：白圆 + 黑 h + 紫点（原版配色，用在黑底结尾）
   - `mark_on_light.svg`：黑圆 + 白 h + 紫点（用在白底开头）
   - `glyph_h.svg`：只有 h + 紫点，透明底（放进玻璃里，用在 4 个镜头）
   - `lockup_on_dark.svg` / `lockup_on_light.svg`：圆标 + hely.fun 整组，间距、比例和原图完全一致
   - 每个 SVG 另导一张 4096px 宽的透明 PNG
5. **验收**（输出 `out/logo_check.png`）：
   - 把 SVG 按原图尺寸栅格化，和原图阈值蒙版做差，IoU ≥ 0.985，差异图贴出来
   - 分别放在纯白、#808080、纯黑、一帧篝火画面上各贴一次，400% 放大看边缘：**不准有黑边、白边、灰边，不准有锯齿和噪点**
   - h 的直边必须是笔直的，圆必须是正圆

**你要先自己再测一遍**：用 crop 后的参考片逐帧（20fps 实际帧）把每个阶段的起止帧、玻璃在画面里的位置和大小（占画面宽度的比例）测出来，写进 `docs/ref_analysis.md`，再开始做。我目测的大小：镜头里玻璃最大约占画面宽 26%；结尾玻璃约 28%；字标宽约 32%。

### 玻璃形状
我们的图标是圆的，所以**玻璃保持圆形**（`uShapeN` 保持 2 左右，不要变成苹果那种圆角方砖）：水滴 → 清透玻璃圆片（厚边、斜面、边缘彩色色散、右上方高光）→ 消散。玻璃圆片本身就代表 logo 的外圆，里面的白色 h + 紫点就是图标。圆形没有转角，原内核里很多色散是按"四个角"算的，要改成沿整圈边缘都有色散，右上和左下两段最明显（对照参考片砖块的色散位置）。

### "通透"的标准
- 玻璃成形后（+0.3 秒到消散前），**中间必须清透**：后面画面的亮度和清晰度要和玻璃外基本一样，只有边缘一圈折射、放大、色散。不能发灰、发白、发雾
- 只有刚出现的水滴阶段（前 0.15 秒）允许乳白

## 5. 节奏表（用户特别强调："什么时候放大、跳得慢还是跳得快，都要刻意"）

剪辑点完全照参考片（每镜 1.5 秒），**镜头内部**按下面的节拍做变速和推近。`r` = 镜头内的时间（秒），半拍 = 0.375 秒。
所有变速用平滑曲线过渡（3–4 帧的缓动），不要突变；所有缩放围绕标注的中心点。

| 镜头 | 节奏意图 | r 0–0.375（第 1 个半拍） | r 0.375–1.125（中间 2 个半拍） | r 1.125–1.5（最后半拍） |
| --- | --- | --- | --- | --- |
| ① 篝火 | **慢进快出** | 正常速度 1.0×，画面 1.00 倍 | 慢动作 **0.5×**（火焰翻滚变慢，玻璃悬着），缓慢推近 1.00 → 1.06 | 提速到 **1.6×**，加速推近 1.06 → 1.12，硬切在拍点上 |
| ② 头发 | **全片高光，猛推 + 慢动作** | 1.0×，源时间从约 1.05 秒开始，画面 1.00 倍 | 在 r=0.375（头发刚扬起，源约 1.375 秒）**猛推** 1.00 → 1.28，0.25 秒内完成，先快后慢（easeOutExpo），推向她的头部；接着 **0.4× 慢动作**走过头发最高点（源 1.4–1.9 秒） | 回到 1.0×，继续微推 1.28 → 1.32 |
| ③ 生成·夜街 | **快、跳** | 1.25× | 1.25×；在 r=0.375 和 r=1.125 各一次**跳推**（3 帧内 +8%：1.00 → 1.08 → 1.16），像鼓点 | 1.25× |
| ④ 生成·花店 | **先慢后快，车擦黑** | 0.7× 慢动作，画面 1.08 倍慢慢**拉远** → 1.04（和前面几镜反向，喘口气） | r 0.75 起 1.0×，拉远到 1.00；车开始入画 | 车身擦过，约 r=1.3 画面基本全黑，留小 h 在车身模糊上 |
| 结尾 | **稳、慢** | 纯黑，没有镜头运动 | 玻璃动作比镜头里慢，照参考片 | 字标定住后停至少 1.2 秒 |

镜头②的慢动作：Live 只有 28.74fps，0.4× 会卡。先试 ffmpeg `minterpolate=mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1` 插到 72fps 再取帧；**放大看头发有没有撕裂、拖影**。如果有，慢动作改成 0.6× + 帧混合，并记进 DECISIONS.md。
镜头② 1280×720 推到 1.32 倍会发软：用 Lanczos 放大 + 轻微锐化（unsharp 0.4 左右），不要过锐。

**玻璃时间点**（每个镜头都一样，按参考片实测微调）：r=0.15 水滴出现 → r≈0.3 铺成玻璃圆片 → 玻璃停留、微漂 → r≈1.2 消散只剩白色 h → r=1.5 硬切。
**玻璃跟着画面动**（用户原话："一直在动态的视频里面去一起动"）：每个镜头选一个主体点（①面具/胸口、②她头部左侧的湖面——让被吹起的头发正好扫过玻璃边缘被折射、③④人物上半身），用 OpenCV 光流跟踪这个点，平滑后作为玻璃中心；再叠上上面的推近/拉远，**玻璃和画面一起被放大**。玻璃不要挡住镜头②头发最好看的那一下。

**声音**（原创，不用参考片的声音）：80 BPM 代码合成，写在 `music.py`
- 每个切点（1.133 / 2.633 / 4.133 / 5.633 / 7.133）一下低频鼓
- 每次水滴出现一声短的玻璃"叮"（高频、带一点混响）
- 镜头②猛推前 0.3 秒一个短的上扬，推的那一刻落下
- 镜头④车开过的呼啸声
- 结尾字标定住时（约 9.6 秒）一个柔和和弦，到 10.8 秒淡出
- 音量要克制，峰值 −3 dBFS，整体 −16 LUFS 左右

## 7. 技术方案

### 7.1 玻璃内核要改的地方
现在的内核只折射它自己的 logo，背景是一个纯色（着色器里 `vec3 back = mix(uBg, uPlateCol, uIconPlate);`，玻璃外是 `bg`）。镜头①–④需要玻璃**折射真实画面**：

1. 复制 `glass/vendor/glass-icon-reveal-core.js` 到 `glass/glass-core.js`，文件头保留 MIT 署名（Zanwei Guo）和 CellMotion 来源
2. 加一个背景纹理 `uniform sampler2D uBgTex;` 和开关 `uUseBgTex`
3. 玻璃外：`bg` 改成采样 `uBgTex` 在当前像素的颜色
4. 折射循环里：`back` 改成在**折射后的位置** `sp`（plate 坐标 → 屏幕 uv）采样 `uBgTex`，这样每个波长的偏移都会把画面一起折射、放大和色散；logo（h）照旧叠在上面
5. 渲染器加 `setBackground(imageOrCanvas)`，每帧更新纹理
6. 开头/结尾的字标透镜：参考片里是一个圆形透镜**横向拉开**成胶囊形，字标在透镜里露出，两端色散最强。内核里已有 `stretch` 参数和 `textScene`，先试用它们；对不上参考片就加一个横向拉伸的透镜形状
7. 圆形玻璃的色散沿整圈边缘（第 4 节"玻璃形状"）

### 7.2 渲染方式
- 离线逐帧渲染，保证结果可重复：Python Playwright 打开 `glass/render.html`（本地 http 服务器，端口用 **8794**，8765/8777 可能被别的会话占用），通过 `page.evaluate` 逐帧传入时间 T、背景帧、玻璃中心和大小，渲染后读出 PNG
- 背景帧先由 `prep.py` 按节奏表（变速、推近、跟踪）处理好，输出成 `work/shotN/%04d.png`（1920×1080），玻璃中心坐标写进 `work/shotN/track.json`
- 整片参数集中在 `timeline.json`（切点帧号、每镜源入点、变速曲线、缩放曲线、玻璃时间、大小、跟踪点），所有脚本都读它
