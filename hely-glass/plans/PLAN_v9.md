## 参考到底是什么样（Claude 逐帧放大核对）
`out/v9_ref/ref_shot1_wings.png`（参考镜头①，1.45–2.40 秒，每格约 0.05 秒）、`ref_shot2_wings.png`（镜头②，2.95–3.90 秒）。

不是几条细线，而是方砖**左右两侧各撑出一块透明厚玻璃"翅膀"**：
1. **形状**：竖条形的玻璃带，紧贴方砖左侧边/右侧边向外长出。竖向覆盖方砖侧边的直线段，上下两头跟着方砖圆角收进去（两端是圆弧，不是平头）。上下边没有
2. **带子里面**：背景被**横向强烈挤压/拉伸成竖条纹**（像透过厚玻璃侧壁斜着看，看到的是被拉成竖线的背景），略微提亮
3. **外沿**：2–3 条挨得很近的亮线（间距 3–6px，最外一条最亮，带一点青/橙色边），内侧（贴方砖那边）一条细暗线
4. **时间**（镜头内 r）：
   | r | 状态 |
   | --- | --- |
   | < 0.42 | 没有 |
   | 0.42 – 0.58 | 撑开，宽度从 0 长到最大 ≈ 方砖宽的 14%（easeOutCubic） |
   | 0.58 – 0.66 | 最宽，带一点左右晃动（±1.5% 方砖宽，约 2 次） |
   | 0.66 – 0.85 | 缩回到 0（easeInOutCubic），缩的时候外沿亮线留下 1–2 条淡残影线，在原地 0.12 秒内淡掉 |
   | > 0.85 | 没有（玻璃开始退场） |
5. 镜头①②最明显；③④同样做

## 实现建议（每帧后处理，左右对称）
- 方砖当帧边界：用 v8 的 glassinfo（render.py 已导出每帧方砖尺寸、形状、透明度）
- 设侧边 x = x_e（左边 x_e = 960 − 半宽，右边对称），翅膀宽 W(r)
- 带内（x_e 往外 0…W）：采样位置 `src_x = x_e ± (x − x_e)·k`，k ≈ 0.22（把贴边很窄一段背景拉宽 → 竖条纹）；再做 5–7px 的横向模糊；亮度 +6/255
- 竖向范围：侧边直线段全长；两端用和方砖圆角同半径的圆弧收进去（越靠端点，带宽越窄）
- 外沿亮线：带的外边界画 3 条，间距 4px，不透明度 0.75 / 0.45 / 0.25，宽 1.5px；最外一条加 1px 青色（外）和橙色（内）彩边
- 内侧暗线：贴方砖边 1px，0.2
- 残影：缩回阶段，在 W 最大处保留外沿线，0.12 秒线性淡出
- 黑场（214–257 帧）：背景纯黑，只画外沿亮线（冷色，亮度 ×0.6），时间换算成黑场玻璃自己的 r
- 方砖本身、光学、h、双线都不动
