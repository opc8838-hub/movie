# v7 追加：镜头内"慢—快"变速（用户追加，和上面一起做）

用户原话："有些节奏还是不太对，比如滑板，还有别的——就是刚好 logo 震动那时候，那个要动的动作画面，它是有一个慢动作的。"

## Claude 实测参考（光流运动量，排除中间玻璃区域，录屏有重复帧所以按 0.1 秒成对看）
- 镜头①转盘：r 0–0.2 正常（约 6.5）→ **r 0.27–0.6 降到约 4（变慢约 0.6×）** → r 0.77–0.9 突然加快（约 7.8）→ 之后约 5.4
- 镜头②滑板少年：整镜都是慢动作（运动量一直很低且平稳）
- 镜头③红裙歌手：r 0.6–0.9 最慢 → **r 1.0 以后明显加速**冲到切点
- 镜头④花店：r 0.9 之前一直慢 → r 1.0 后车进来猛加速（运动量从 1 升到 8）

**规律**：水滴落下、logo 震动（r ≈ 0.15）起画面放慢，玻璃在的这段（约 r 0.2–0.95）是慢动作，玻璃退去后（r ≈ 1.0）加速冲进切点。

## 改法：4 个镜头统一用这条速度曲线（镜头内时间 r，平滑过渡，不要突变）
| r | 速度 |
| --- | --- |
| 0 – 0.15 | 1.0× |
| 0.15 – 0.28 | 平滑降到 0.45× |
| 0.28 – 0.95 | 0.45× 慢动作（水滴、玻璃、震动都在这段） |
| 0.95 – 1.12 | 平滑升到 1.6× |
| 1.12 – 1.5 | 1.6×，冲进硬切 |

- 镜头②头发原来就是类似结构（0.4× 慢动作 + r 0.375 猛推），保持现有的就行，只把慢动作开始提前到 r ≈ 0.2，让头发扬起落在慢动作里
- **选入点**：每一镜的主要动作要落在慢动作段的前半（r ≈ 0.2–0.5），正好和水滴落下、logo 震动同时：
  - 镜头①篝火：举刀/举锣的动作起点在 r ≈ 0.2
  - 镜头③滑板：起跳在 r ≈ 0.18，**最高点在 r ≈ 0.40**（慢动作中滞空）
  - 镜头④花店：她转圈落在 r 0.2–0.6；**车在加速段（r ≥ 1.0）冲进来**，第 214 帧硬切黑
- **慢动作要插帧，绝对不能卡**：篝火 30fps、滑板和花店 24fps，0.45× 不插帧一定卡顿。用 `minterpolate=fps=120:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1` 插到 120fps 再按速度曲线取帧（镜头②已有 72fps 插帧可复用）。插完 200% 放大检查人物边缘、头发、滑板、火焰有没有撕裂或重影；某一镜插帧坏得明显，就那一镜改用帧混合，并写进 DECISIONS
- 镜头内的推近/跳推节点跟着新的动作时间走；声音里镜头内的重音（滑板最高点等）也挪到新时间
- 质感处理、水波、玻璃时间、玻璃光学都不变
