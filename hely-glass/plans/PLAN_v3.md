## 2. 新的字标展开效果 `tools/wordmark_lens.py`（开头 + 结尾）

**先看参考**：`out/v3_ref/ref_open_native.png`（参考片 0–1.13 秒逐帧，约 20fps，从左到右、从上到下）和 `out/v3_ref/ref_end_native.png`（7.9–9.9 秒）。我（Claude）已经拆解过，过程如下：

1. **0–0.18 秒，圆透镜**：一个圆形透镜，直径约为最终字标高度的 3 倍。里面是被放大、**打着旋**的字标中心部分（像漩涡一样卷起来）。透镜边缘有一圈亮边，外面是一圈圈淡淡的同心水波往外扩
2. **0.18–0.42 秒，横向拉开**：漩涡逐渐松开，透镜向左右拉宽成横向胶囊形。中间的字变正常，**两端的字被横向拉长**，越靠边拉得越长，红、绿、蓝三个通道拉的长度不同 → 两端出现浓烈的红/蓝色光条（左端偏蓝紫，右端偏红）。两端的字也略微变高
3. **0.42–0.75 秒，收拢**：正常区域扩大，拉长和色散快速减弱，0.6 秒时整组字标完整可读
4. **0.75 秒以后，余韵**：只剩两端很细的彩色描边和一点重影，水波还在淡淡外扩

透镜本身**没有可见的玻璃方块轮廓**（这点和动效库方块玻璃不同）；只在第 1、2 阶段有一圈淡淡的亮边。

### 实现（numpy + cv2.remap，逐帧生成，最后覆盖到 frames）

- 先画底图 `base`：1920×1080，底色（开头 #e9e9e9 / 结尾 #000000）上居中放字标（开头 `assets/logo/lockup_on_light.png`，结尾 `lockup_on_dark.png`），宽 806px，Lanczos 缩放、正确 alpha 合成
- 记号：`hw` = 字标半宽（403），`hh` = 字标半高；`X = x-960`，`Y = y-540`；时间 `τ`：开头 `τ = t`；结尾 `τ = (t - 8.6) / 1.25`（结尾整体慢 1.25 倍，用户嫌原来结尾太快）
- **透镜形状**：超椭圆 `(|X|/A)^4 + (|Y|/B)^4 ≤ 1`
  - `B = 1.8·hh`（不变）
  - `A`：τ < 0.18 时 `A = B`（圆）；0.18–0.42 用 easeOutCubic 从 `B` 长到 `1.10·hw`；之后保持
  - 透镜外只显示底色（加第 2 步的水波），透镜内用下面的映射采样 `base`
- **漩涡 + 放大**（τ < 0.40）：`ρ = √(X²+Y²)`，`φ = S(τ)·(1 - min(ρ/A, 1))²`，`S(τ) = 2.6·(1 - smoothstep(0.05, 0.36, τ))`（弧度）。采样点 = 把 (X, Y) 旋转 φ 后除以放大率 `M(τ) = 1 + 1.4·(1 - smoothstep(0, 0.42, τ))`
- **两端拉长 + 色散**（τ ≥ 0.15）：
  - 正常区半宽 `a(τ) = hw·(0.30 + 0.66·smoothstep(0.20, 0.60, τ))`
  - 拉长系数 `k(τ) = 0.20 + 0.80·smoothstep(0.25, 0.65, τ)`（< 1 表示拉长）
  - 色散 `D(τ) = 0.35·(1 - smoothstep(0.30, 0.95, τ)) + 0.05·(1 - smoothstep(0.95, 1.6, τ))`
  - 每个通道 c（R = +1，G = 0，B = −1）：`|X| > a` 时 `Xs = sign(X)·(a + (|X| - a)·k·(1 + c·D))`；`|X| ≤ a` 时 `Xs = X`
  - 两端变高：`Ys = Y / (1 + V(τ)·smoothstep(a, A, |X|))`，`V = 0.30·(1 - smoothstep(0.30, 0.70, τ))`
  - 拉长区内做横向模糊：沿 x 取 5 个样本平均，展开量 `0.3·(1 - k)·(|X| - a)`
  - 漩涡和拉长在 0.15–0.40 重叠时，先做漩涡再做拉长
- **透镜亮边**：超椭圆边缘内侧 3px 带。白底提亮 +18/255，黑底加冷色 (0.80, 0.87, 0.97)×40/255；随 `1 - smoothstep(0.30, 0.50, τ)` 消失。白底外侧再加一圈 −6/255、宽 20px 的软阴影
- **水波**（第 1.4 条"左右两边的波纹"，必须明显可见）：以 (960, 540) 为圆心的 3 道同心环，第 k 道半径 `R_k = A(τ) + 60k + 500·τ`（px），环的横截面用高斯导数（一亮一暗，宽 14px，看起来像水面折射），振幅 `7/255·exp(-τ/0.6)`；白底再叠一层 `ρ < 1.35A` 范围内 −5/255 的柔和灰晕，1.0 秒前淡出。黑底振幅 +6/255、冷色调
- **开头**：用到第 33 帧（1.1 秒），第 34 帧硬切镜头①
- **结尾**：8.6 秒（第 258 帧）开始。v2 里 8.38–8.6 秒白色 h 换成实心圆标并缩小，保留这一段；圆标缩到和透镜初始大小一致时，无缝接入第 1 阶段的圆透镜。10.2 秒（第 306 帧）完全干净，之后静止字标一直停到 12 秒，11.5 秒起整体淡黑（v2 已有，保持）
- 结尾 10.2–12.0 秒的静止字标也改成 806px（render_v2.js 的 `directLockup`，或者全部用 Python 画）
- **参数按参考片调**：上面的数字是起点，不是终点。每改一次就出一张"我们 vs 参考"的同时刻对比图（第 6 节），调到两端色散浓度、拉长程度、各阶段时间点都和参考片一致为止

## 3. 4 个镜头 + 黑场玻璃的水波

用户说"水波震动的时候，左右两边还有波纹"。v2 只用了原版着色器的 ripple，在视频上几乎看不见。加一道独立的水波：
- 在 prep 阶段对背景帧做**径向位移**（不是画亮线）：水滴出现（镜头内 r = 0.15）开始，2 道同心环，半径 `R = 0.5·玻璃宽 + 700·(r - 0.15)`（px），间距 70px，环宽 22px，位移振幅 `6px·exp(-(r - 0.15)/0.35)`，r = 0.9 后结束。圆心 = 当帧玻璃中心（镜头③会动，见第 4 节）
- 黑场（7.133 秒起）背景是纯黑，位移看不见，改成第 2 节那种亮度水波（+6/255，冷色）
- 波纹要能在 100% 画面上看出来，但不能抢玻璃的戏

## 8. 补充（用户追加）：黑场玻璃没有折射；总原则 1:1 对标原片

用户原话："当画面黑色之后，那个 logo 是没有折射的。反正就是要 1:1 地对标好原视频。"

**原因（Claude 已对比 `out/v3_ref/v2_end_vs_ref_problem.png`）**：参考片黑场 7.2–8.1 秒，白色音符几乎撑满玻璃方砖，笔画（符干、符尾、符头）伸进了方砖的厚边斜面，所以斜面把白色笔画折弯、拉长、分出彩虹色。我们的 h 离玻璃边留得太宽，斜面后面只有黑色，折射了也看不出来。

**改法**：
- 黑场玻璃（`render_v2.js` 的 `endingGlass`）：调大 logo 在玻璃里的占比（`logoScale` / `finalScale` / 玻璃尺寸之间的关系），让 h 的竖笔画顶端、右腿和紫点**伸进方砖斜面带**，位置和参考片音符笔画伸进去的位置相当（左上、右下）。光学公式不改，只改"logo 有多大、玻璃有多大"
- 逐帧和参考片 7.2–8.1 秒对比，目标：方砖四边都能看到被折弯的白色笔画和彩虹色散，浓度和参考一致；冷色边光、厚边感一致
- 4 个视频镜头里的玻璃也检查一遍：参考片镜头①–④里，音符同样伸进斜面、边缘有强烈彩色折射。我们的 h 如果离边太远，同样调大占比
- 验收图 `out/v3_endglass_vs_ref.png`：我们 7.2–8.2 秒 vs 参考 7.2–8.1 秒，每 0.1 秒一帧并排；`out/v3_shotglass_vs_ref.png`：每个镜头玻璃最饱满的一帧 vs 参考对应镜头

**总原则**：每一段都要和参考片同一时刻的画面并排比，**动作、时间点、大小比例、折射和色散强度做到 1:1**。只有这些可以不同：内容换成我们的（h 圆标、hely.fun、我们的 4 个镜头），以及用户明确要求的改动（结尾放慢到 12 秒、字标放大到 42%、镜头③玻璃跟人动、跳起前置、篝火快推）。发现任何和参考不一致又不在这个清单里的地方，按参考改。
