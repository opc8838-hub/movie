## 1. 开头字标的灰色全部清掉（第 0–33 帧，`wordmark_lens.py`）

`user_open_gray.jpg`：v7 开头字标周围有一大片灰色——v6 加的"灰椭圆边"（−8/255）、白底柔影、泡外旋涡纹，以及左侧一条横向灰带，在定住的字标周围一直留着，看起来脏。
- **删掉**：灰椭圆边、白底大高斯柔影、泡外旋涡淡纹、任何让背景变暗的层
- **保留**：透镜内的漩涡/拉长/色散、左右弧形震动波（v7，0.15–0.5 秒）、亮椭圆泡可以保留但只准**提亮**、并且 0.6 秒前淡完
- **0.6 秒以后，字标外的背景必须是干净的纯色 #e9e9e9**（逐像素检查：字标外接框外扩 40px 以外的区域，和 #e9e9e9 差 ≤ 1）
- 震动波本身也不能留下灰影：它是一暗一亮的折射带，过去就没了
- 结尾黑底（258–305 帧）同样检查：10.2 秒以后字标外是纯黑

## 2. 篝火镜头①更动感：推拉远近 + 震动瞬间慢动作再加速（第 34–78 帧）

保持 v6/v7 的前提：用原片完整画面（1088×720 等比放到宽 1920、上下裁 1080、偏上 12%），不 deblock、不右扫，入点附近的动作卡点保留。在此基础上：
- **推拉（镜头缩放，围绕画面中心偏上、面具附近）**：
  | r | 缩放 |
  | --- | --- |
  | 0 – 0.15 | 1.00 → 1.10 快推（easeOutCubic），切进来就往里冲 |
  | 0.15 – 0.90 | 1.10 → 1.02 慢慢拉远（慢动作里"呼一口气"） |
  | 0.90 – 1.50 | 1.02 → 1.20 加速猛推（easeInCubic），冲进硬切 |
- **速度**（比 v7 更明显）：
  | r | 速度 |
  | --- | --- |
  | 0 – 0.13 | 1.2× |
  | 0.13 – 0.20 | 平滑降到 0.30× |
  | 0.20 – 0.90 | 0.30× 慢动作（水滴落下、logo 震动、玻璃都在这段） |
  | 0.90 – 1.05 | 平滑升到 2.0× |
  | 1.05 – 1.50 | 2.0× |
- 慢动作必须插帧：`minterpolate=fps=120:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1`（v7 已有 `work/v7/interp/shot1.mp4`，0.30× 不够时重插到 150fps）。200% 放大检查火焰、刀、锣边缘没有撕裂；插帧坏得明显的区域改帧混合
- 加速段（2.0×）每帧做 3 子帧平均的运动模糊，让冲刺有速度感
- 重新算源时长，确保不超出素材；入点按需要微调，让刀/锣的动作起点仍然落在 r≈0.15–0.2（logo 震动那一刻）
- 声音：镜头①的轻底鼓挪到 r=0.15（慢下来那一下）和 r=0.95（加速那一下），加速段加一声短的"呼"
- 玻璃仍固定画面正中，不随画面缩放
- 验收：`out/v8_fire.png`（每 0.05 秒一帧）、`out/v8_fire_speed.png`（运动量曲线，标出 r=0.15/0.2/0.9/1.05）

## 3. 玻璃方砖左右两侧的"水波纹"（4 个镜头，第 34–213 帧；黑场 214–257 帧也加，弱一点）

**参考是什么样**（`ref_tile_sides.png`，用户截图 2、3 红圈处）：方砖成形以后（镜头内 r≈0.35 起），方砖的**左、右两条侧边各被"复制"出 2–3 条向外荡开的回声边**——
- 每条回声边是一条**细的透明玻璃竖边**：形状和方砖侧边一样（竖直段 + 上下两端圆角弯进去），竖向长度约为方砖高的 0.8–0.9 倍
- 外观：一条 1–2px 的亮高光线（白，约 40–60% 不透明）+ 紧贴它的一条细暗线，中间那窄窄一带把背景**横向折弯/错位**（像透过一片薄玻璃的边看过去），边上带一点点彩色（青/橙）
- 位置：从方砖侧边往外排，间距约为方砖宽的 4–6%，第 1 条最清楚，越往外越淡
- 运动：随时间往外荡开一点（r 0.35 → 0.95 外移约 3–5% 方砖宽），并有轻微的左右晃动（像水波来回），玻璃退去时一起消失
- **上下两边几乎没有回声**，主要就是左右
- 参考镜头①、②在 r≈0.5–0.9 最明显；用户在截图里说"很明显"，所以要做到正常观看一眼能看到

**v7 我们**：只有很淡的圆角方形位移环，用户看不出来。

**改法**：
- 去掉 v6/v7 的圆角方形位移环（prep 里那一步），换成上面的"左右回声边"
- 实现建议：在 build 阶段对渲染好的帧做后处理（方砖外的区域就是背景）。每帧需要方砖当前的位置和大小：中心固定 (960, 540)，尺寸可以用 `glass/glass-core.js` 的 `frameAt()` 里的 `uPlateScale` × tile（镜头 610 / 黑场 585）算，或者直接从 `frames_raw` 与背景帧的差异检测方砖边界。每条回声边：
  1. 在边的位置画一条窄带（宽约 10px），带内把像素沿水平方向错位 4–8px（cv2.remap），模拟折射
  2. 带的外侧叠 1.5px 白色高光线（不透明度 0.5 × 衰减），内侧叠 1px 暗线（0.25）
  3. 高光线两端随圆角弯进去
  4. 时间包络：r 0.30 淡入，0.95 起随玻璃淡出
- 黑场（214–257 帧，背景纯黑）：只画冷色亮高光线（没有可折射的东西），亮度减半
- 验收：
  - `out/v8_tile_sides_vs_ref.png`：4 个镜头各取 r = 0.5 / 0.7 / 0.9 三帧，方砖附近放大，和参考同时刻并排（参考取法见 `ref_tile_sides.png`：`crop=592:334:0:335` 后再裁方砖区域放大）
  - 用 Read 亲眼看：正常画面里左右回声边一眼可见，形状像参考
