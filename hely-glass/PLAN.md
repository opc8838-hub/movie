# 玻璃显标 · 通用规格（换品牌 / 换素材时交给执行者）

> 这份规格从 hely 玻璃显标片 12 版迭代里提炼出来。数值都是实测、定稿用过的。
> 执行者照做；遇到没写到的地方，按"和参考同一时刻并排看，一样才算对"的原则决定，并写进 DECISIONS.md。

---

## 1. 每次准备

| 要什么 | 说明 |
|---|---|
| 品牌 logo | 矢量最好。只有位图时按第 4 节重画，不准直接抠图 |
| 4 段画面 | 每段至少 3 秒，要有**明确的动作起点**（甩头、起跳、举手、车经过） |
| 一首歌或一个 BPM | 没有歌就用 80 BPM 代码合成 |
| 一句想要的感觉 | 比如"热烈""安静""速度感" |

---

## 2. 结构（80 BPM，30fps）

| 段 | 时长 | 内容 |
|---|---|---|
| 开头字标 | 34 帧（1.133 s） | 纯色底，字标透镜展开，0.6 s 起完整可读 |
| 镜头 ①–④ | 每镜 45 帧（1.5 s = 2 拍） | 画面 + 正中玻璃 logo |
| 黑场玻璃 | 214 帧起 | 纯黑硬切，玻璃再显一次 logo |
| 结尾字标 | 至 12.0 s | 8.6 s 展开，10.2 s 定格，11.5 s 起淡黑 |

**换 BPM：**每镜时长 = 2 × 60 / BPM 秒。镜内所有 r 节点按比例缩放。

---

## 3. 镜头内规则（r = 镜头内秒数，0 → 1.5）

### 3.1 玻璃（不准改）

| r | 节点 |
|---|---|
| 0.15 | 水滴落下（冲击帧） |
| 0.30 | 成形为圆角方砖 |
| 0.95 | 开始退场 |
| 1.22 | 消失，留下白色 logo |
| 1.50 | 硬切 |

- 中心固定 (960, 540)，`drift = 0`，不跟拍
- 方砖 tile 610 px（黑场 585 px）
- logo 占方砖约 75%，笔画要伸进斜面带
- 光学用 light look 原版数值：dispersion 1.7、glow 1.25、edgeSmear 2.85、cornerPull 2.1、cornerWidth 2.2、cornerFocus 0.58、bevelWidth 0.14、opticalDepth 1.1、tilt 0.35
- **不准降低任何光学数值**

### 3.2 变速（按镜头动作强度三选一）

| 档 | 进场 | 慢动作 | 冲刺 | 适合 |
|---|---|---|---|---|
| 强 | 1.2× | 0.30×（r 0.20–0.90） | 2.0×（r 1.05 起）+ 3 子帧运动模糊 | 舞蹈、运动、火 |
| 中 | 1.0× | 0.45×（r 0.28–0.95） | 1.6×（r 1.12 起） | 滑板、街拍、车 |
| 轻 | 1.0× | 0.40×（r 0.25–1.00） | 1.0× | 人像、风吹头发 |

- 速度切换用 smoothstep 过渡
- 慢动作先 `minterpolate=fps=120:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1` 插帧，再按速度曲线积分取样
- 插完 200% 放大检查边缘撕裂

### 3.3 动作对位

- 用 Farneback 光流算每帧运动量，滑动 1.5 s 窗口打分（`scripts/tools/fire_candidates.py`）
- 要求：r≈0.15 有动作起点；r≈0.75 有第二个动作；r≈1.0 主体到最佳位置（脸正对、跳到最高、车进画）
- 前 3 个候选拼图给人选，理由写进 DECISIONS

### 3.4 推拉（可选，只给一两个镜头用）

| r | 缩放 | 缓动 |
|---|---|---|
| 0 – 0.15 | 1.00 → 1.10 | easeOutCubic |
| 0.15 – 0.90 | → 1.02 | smoothstep |
| 0.90 – 1.50 | → 1.20 | easeInCubic |

- 头发、人像改成单次猛推：r 0.275–0.5，1.00 → 1.28，expo 缓动
- **用原片完整画面**，不 overscan，不 deblock

### 3.5 两侧冲击波（`scripts/tools/echo_wave_v12.py`）

参数照抄：

```python
packets=[dict(r0=0.50, s=1.0), dict(r0=0.70, s=0.55)]
travel=0.36  # 方砖宽
dur=0.50     # 秒
gap=0.022    # 两条弧间距，方砖宽
amp=20.0     # 折射错位 px
```

- 运动：`ease = 1-(1-p)^2.4`
- 淡出：`fade = (1-p)^1.6`
- 只画左右两段，上下不画
- 黑场只画冷色亮线

## 4. logo 矢量化（"一定要干净通透"）

- 圆、点用最小二乘拟合正圆；直边用矩形；弧用圆弧
- 字标先试开源字体，IoU ≥ 0.98 用字体轮廓，否则 potrace 描再拉直
- 输出：浅底版、深底版、放进玻璃的单色图形版，以及整组字标
- 验收：IoU ≥ 0.985；白、灰、黑、实拍四种底上 400% 放大，没有黑边、白边、锯齿

---

## 5. 字标展开（`scripts/tools/wordmark_lens.py`）

- 字标宽 = 画宽 42%，始终水平，不旋转
- 过程：圆透镜漩涡 → 横向撑开成胶囊 → 两端 R、G、B 分通道拉长（左端蓝紫、右端红青）→ 收拢定格
- 左右各一道括号形震动波，τ≈0.15 和 0.40 起往外推，0.3 s 内消失
- 0.6 s 后字标外背景逐像素纯色，不留灰影

---

## 6. 生成镜头质感（不改色）

| 处理 | 数值 |
|---|---|
| 轻微柔化 | gblur 0.4 |
| 黑位 | 7/255 |
| 高光 | ≤ 248 |
| 颗粒 | σ≈2.2/255 |
| 亮部光晕 | 4% |
| 暗角 | 无 |
| 色相 | 不动 |

入片前先和实拍镜头比一下锐度和黑位。

---

## 7. 声音

- 切点：底鼓
- 每次水滴：玻璃铃
- 强变速镜头的冲击帧和冲刺点：轻鼓 + 一声"呼"
- 车或其他运动物体：呼啸声，声像跟方向

不用参考片的声音。

## 9. 验收清单

- [ ] 切点帧 34 / 79 / 124 / 169 / 214，无重复帧
- [ ] 玻璃全程在正中，大小一致
- [ ] 每镜 r≈0.15 画面有动作起点，玻璃段是慢动作，退场后加速
- [ ] 两侧波一次一道、往外走、由深到浅
- [ ] 斜面有明显彩虹色散，黑场也有
- [ ] 开头 0.6 s 后、结尾 10.2 s 后背景逐像素纯色
- [ ] 每段和参考同一时刻并排看过，不一样的地方如实写出来

## 10. 不准做的

- 不准降光学强度
- 不准让 logo 漂移、摇摆、跟拍
- 不准把素材放大裁切
- 不准调色
- 不准用参考片的画面和声音
- 不准打印或提交 API 密钥
- 渲染只开一个进程，每 30 帧一段
