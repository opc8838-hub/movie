## 硬规则（用户的偏好，必须遵守）
1. 素材**保持原色**，不加任何滤镜：不加柔化、雾、颗粒、柔光、暗角、色散、漏光、S 曲线，不调色。
2. **不能有停顿感**：不定格，不用重复帧。时长不够的镜头轻微放慢（setpts，0.75–0.95 倍），不用 minterpolate。
3. 人像镜头要多（已按此分配，不要改成空镜）。
4. Windows 中文路径下 cv2.imread/imwrite 会失败，读写图片用 PIL；视频用 ffmpeg 管道 rawvideo。
5. rgb24 → yuv420p 编码时防白底发黄：`-vf scale=out_color_matrix=bt709:out_range=tv:flags=accurate_rnd+full_chroma_int -colorspace bt709 -color_primaries bt709 -color_trc bt709`；读 Live 源时按 bt709 解码。
6. Live 源是可变帧率（约 28.7fps），先统一 `fps=30` 再用。源多是 1280x720，用 lanczos 放大到 1920x1080。
