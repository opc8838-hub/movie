## 歌词踩点剪辑法

这一支 MV 能一次过，靠的是动手前先把素材和参考片吃透。方法分四步：**看、拆、连、创**。

### 第 1 步　看：给每个素材写一张身份卡

每段 Live 抽 10 张缩略图，一张张看完再填卡。卡填完之前，不想镜头怎么排。

| 栏目 | 写什么 | 为什么要写 |
|---|---|---|
| 谁、在干嘛 | 一句话，动词要具体："长椅上回头笑"，不写"人" | 词义配对靠它 |
| 最好的一刻 | 第几秒到第几秒 | Live 只有 3 秒，往往只有 1 秒能用 |
| 人像还是空镜 | 二选一 | 决定它能不能扛高潮；"人像要多"就按这个标记调 |
| 横还是竖 | 横 / 竖 | 决定要不要裁、怎么裁 |
| 形状和颜色 | 圆的、直线、红的、冷灰的 | 形状呼应全靠这一栏 |

### 第 2 步　拆：把参考片拆成表

参考片每个镜头一行：几秒到几秒、唱什么、意思是什么、拍的是什么。每一行都是一个空位，等着放自己的素材。

每个词出现的时间，这次是从参考片里量出来的：参考片的字是橙色，让电脑逐帧数橙色像素，数量一跳就是有新词出现，误差约 0.05 秒。

### 第 3 步　连：两张表配对

1. **先定故事，再配镜头。**歌词是"收拾东西离开你"，结尾那句是"欢迎回到拉斯维加斯"，所以整片从拉斯维加斯出发、绕一圈美西再回来，头尾都是 Sphere。
2. **按词义配：**"Leave you behind"配公路上背影走远。
3. **按景别配：**参考片是航拍，就换成同样开阔的湖景；参考片是人走下台阶，就配人在走。
4. **按形状配：**参考片的圆形粉湖，换成红色圆球。
5. **最好的镜头留给高潮：**长椅回头笑放在 "Fool"。
6. **空镜要短：**空镜每个只给 0.6 到 1.2 秒，长的空位从中间切开，插进人像。

### 第 4 步　创：从麻烦里找创新

不要先想"做点什么酷的"。先碰到放不下、会挡住、没词可卡的麻烦，再想办法解决。

| 碰到的麻烦 | 解决办法 | 规律 |
|---|---|---|
| 4 段竖拍素材放进横屏要裁掉一大半 | 三格竖着并排，唱 Leave / You / Be- 各亮一格 | 画面切换卡在词上，比卡在鼓点上更有跟唱的感觉 |
| 最好的镜头人在正中，巨大的 Fool 会挡脸 | rembg 逐帧抠人，叠成背景、字、人三层 | 字和人有了前后关系，画面就有了纵深 |
| 音乐唱完了，结尾那句话没有歌可以卡 | 沿用逐词跳字，只把最后的名字换成白色手写；最后一个音加回声拖到结尾 | 新加的部分沿用前面的做法，只在最后一个词上变 |

## 分工

1. **Claude（Opus）：**看完全部素材和参考片，填身份卡、拆表、测词时间。
2. **Claude（Opus）：**出镜头表和创新点，写成大白话方案。
3. **我：**拍板。这次定的是横屏、三个创新都要、人像要多。
4. **Claude（Opus）：**把方案和所有规矩写进 `PLAN.md`。
5. **Sonnet：**照 `PLAN.md` 写脚本出片，自己先检查一遍。
6. **Claude（Opus）：**放大到原尺寸验收，没问题再交给我。

### 踩过的坑，已经写成规矩

- **素材保持原色，不加滤镜。**柔化、雾、颗粒、柔光、暗角、调色都不要，我要的是相机直出的感觉。
- **不定格，不放太慢。**时长不够时只轻微放慢（0.75 到 0.95 倍）。
- **交付前按原尺寸放大看。**只看缩略图会漏掉发白、发糊、抠图毛边。
- **先锁定认可的版本，只改点名的地方。**大改方向最容易把好的部分也改掉。

## 下一步：换成任意一首歌

没有参考片时，词的时间和节奏从歌本身测出来。不需要专门的音乐大模型，下面这些本地免费工具就够：

| 工具 | 做什么 |
|---|---|
| Demucs | 把人声和伴奏分开，伴奏太响会干扰识别 |
| Whisper（faster-whisper） | 在人声里对出每个词的时间；同时给它歌词文本，它只对时间、不猜词 |
| librosa | 找节拍、画能量曲线，看哪里副歌、哪里最响 |
| Claude | 读歌词意思、看能量曲线，分段、定切点、配素材，写镜头表 |
| Sonnet | 照镜头表出片 |

工具测出的数只是草稿。比如 librosa 给这首歌测出 172 BPM，大概是实际速度的两倍，这种误差要人听一下判断。

**每次准备这四样：**一首歌（只截要用的那段更好）、歌词文本、一批素材、一句想要的感觉。

## 文件说明

```
index.html                     在线学习页（由 build.py 生成，不要手改）
jd-lasvegas/
  PLAN.md                      交给 Sonnet 的完整执行说明：镜头表、歌词时间、硬规则
  render.py                    一键出片脚本，参数都在文件头
  guide/
    template.html              学习页源文件，图片用 {{名字}} 占位
    img/                       学习页用的截图
    audio.json                 音乐能量曲线和节拍数据（librosa 测的）
    build.py                   把截图和数据嵌进 template.html，生成根目录 index.html
```

改了学习页之后，重新生成：

```
python jd-lasvegas/guide/build.py
```

原始素材、参考片、音乐和成片视频没有放进仓库，在本机 `E:\claude工作区\jd-mv2`。`render.py` 需要这些文件才能出片，路径写在它的文件头。
