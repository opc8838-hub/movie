# 02 审美原则

这些原则来自主理人否掉每一版时说的话，不是从书上抄的。

状态：v0.1 草稿，等主理人删改。每条写成“原则 + 交片前问自己的一句话”，括号里是来源。

**一句话总结：真实、克制、留出呼吸，让主角站出来。**

## 运动

| # | 原则 | 交片前问 |
|---|---|---|
| 1 | 丝滑不是一直动，是动静交替（专利翻阅 v2 “看晕了”） | 每个镜头有没有完全静下来、让人看清楚的瞬间？ |
| 2 | 同一时刻只做一种运动（专利翻阅、三大系统） | 暂停任意一帧，运动方向超过两种吗？ |
| 3 | 跟原片学速度，不跟原片比用力（专利翻阅放大倍数被压回约 2 倍） | 我的缩放和速度比参考夸张一倍以上了吗？ |
| 4 | 段与段要接得住，结尾不能卡一下（jd “人物停下那刻不能有停顿感”） | 交界处速度是不是突然掉成零？ |
| 5 | 同类之间溶过去，不同类之间直接切（三星堆竖屏） | 这一刀前后是同一件事，还是换了一件事？ |
| 6 | “丝滑”先查速度曲线（第三段实测点逐点穿过，变成忽快忽慢） | 曲线在关键帧上有没有掉零或抖动？ |

## 看起来矛盾的规矩

这些规矩放在一起像是冲突的，其实分片型。

### 要不要加质感

| 片型 | 怎么做 | 依据 |
|---|---|---|
| 真人实拍片 | 默认原片色。最多很淡的颗粒（0.006），不加雾和柔光 | jd v5 被认可，v6–v9b 全错；拉斯维加斯完全不加 |
| AI 镜头混实拍 | 量出和实拍的差距，补到看不出来 | hely 玻璃 |
| 风格化短片 | 用户明确要电影感时可以加重 | MV2、MV3 |
| 2D 动画 | 不加颗粒和柔光，保持干净【借鉴】 | Eian |
| 白底品牌片 | 暗角只压暗部，白点留到 254 | 连盈 |

### 慢动作要不要补帧

| 场景 | 怎么做 | 依据 |
|---|---|---|
| 风景、火焰、发丝的节奏变速 | 运动补偿插帧，放大检查边缘 | hely 玻璃 |
| 脸、手、刀这类细节 | 不补帧，用真实速度或只轻微放慢（0.75–0.95 倍） | Nobody、jd 拉斯维加斯 |
| 补帧有重影但感觉好 | 帧混合拖影也是一种风格，让用户判断 | jd 指天镜头，曾被去掉，后来要求放回 |

### 转场：溶化、硬切还是失焦

| 情况 | 用什么 | 依据 |
|---|---|---|
| 同类图片连续变化 | 溶化 | 三星堆竖屏 |
| 换一件事 | 硬切 | 无重力翻转 |
| 有人物的两段视频 | 不用长溶化（重影）；可试 0.4 秒高斯失焦，最糊处硬切 | 立体世界 LA 卡 |
| 帧序列旋转 | 不交叉淡化，只显示单帧（相邻帧叠在一起就是重影） | 衣架站 |

### 用不用参考片的东西

| 用途 | 规矩 |
|---|---|
| 学节奏、结构、动态语法 | 可以，这是学习的正路 |
| 个人练习、内部测试用参考片音乐或画面 | 可以，但不对外商用 |
| 对外发布、商业片 | 不用别人的画面和声音。声音换原创或正版，画面重做 |

**我们学的是语法。** 玻璃效果很快会被用烂，节奏、动作对位、变速这些语法才带得走。

## 主理人的话怎么翻译

| 主理人说 | 通常的意思 | 先查什么 |
|---|---|---|
| 丝滑、有呼吸感 | 动静交替，运动少叠加，缩放别过头 | 速度曲线、同时几种运动 |
| 看晕了 | 镜头一直在动，没有落点 | 加停顿 |
| 太慢了 | 入场慢，或者确认太多 | 砍时长，少问 |
| 假、像生成的 | 过锐、死黑、背景飘、人和背景错层 | 量锐度和黑位，查是否拆层、补帧 |
| 土 | 奶白罩层、硬底、硬平移 | 换景深和光影，减元素 |
| 滤镜太重 | 黑位被抬灰、肤色变了 | 和原片并排放大看 |
| 太灰白 | 同上，方向走偏 | 回到认可版本 |
| 不高级 | 用力过猛，元素太多 | 减法 |
| 有质感、厚重 | 线粗一点，有辉光和玻璃体 | hely v11 |
| 差点细节 | 机制对了，节奏或层次不对 | 回参考片逐帧看，不要重写 |
| 不如之前 | 方向错了 | **立刻回到认可版本** |

## 主理人的长期偏好

- 标杆：苹果发布会、Jony Ive 白底讲述、日系胶片 MV
- 喜欢大主体、快入场、真实素材
- 技术段要推拉平移快剪，人文段慢、暖、不煽情
- 结尾用一句有温度的话，不用口号
- 人物片里露牙的侧脸镜头要少用；插画人物嘴不能张开
- 默认不用定格和多余的停顿，除非主理人点名要
