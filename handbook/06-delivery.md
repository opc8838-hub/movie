# 06 交片与复盘

---

## 交片前自查

每次交片之前，AI 逐条过一遍。这些都是主理人实际指出过的问题：**先由我们自己挑掉，主理人就只需要谈审美。**

先出总览图，每 0.5 秒一格，逐格看；有疑问的地方按原尺寸放大。

### 画面

- [ ] 没有发白、发灰（HDR 转了吗？滤镜把白底压灰了吗？）
- [ ] 白是真白，不发黄、不发绿、不发粉
- [ ] 黑还是黑，头发没有变灰
- [ ] 素材原色没被改动；和原片并排看过
- [ ] 抠像边缘干净，没有绿边、残影、缺块
- [ ] AI 的脸没有变形，同一个人每个镜头长得一样
- [ ] 没有平台水印、别家品牌、禁用素材
- [ ] 没有黑点、破洞、重影、跳帧、重复帧
- [ ] 同一个镜头没有重复出现（故意首尾呼应除外）
- [ ] 没有糊的素材，低清素材已还原或删除
- [ ] 产品画面里没有手

### 字

- [ ] 我们加的字只有黑白灰（除非方案另有说明）
- [ ] 字不出画、不压脸
- [ ] 中英字幕在亮、暗背景上都看得清，时间对齐
- [ ] 没有孤字成行，没有拼写错误
- [ ] 数字和参数表一致，客户禁用词全片没有出现（字幕、配音、画面字、头衔都查）

### 节奏和声音

- [ ] 切点对准拍点，抽查切点前后 3 帧
- [ ] 动静交替，有能看清的停顿，也有快的地方
- [ ] 交界处没有卡一下
- [ ] 开头 3 秒有内容，没有空等
- [ ] 响度统一，没有被截断的字
- [ ] 物体落下有重量（接触帧轻震 + 声音）
- [ ] **声音和动态手感 AI 判断不了，已明确告诉主理人**

### 手机上看

- [ ] 缩到手机大小看一遍，主体够大，字看得清
- [ ] 竖屏片的字和主体在安全区内

### 交付

- [ ] 旧版已备份，文件名带版本号
- [ ] 有正式版和微信版
- [ ] 文件放到约定的文件夹，路径告诉了主理人
- [ ] 回复时说清楚：改了什么、还有什么问题

---

## 版本规矩

- 新版本存新文件，不覆盖、不删除旧文件
- 文件名：`片名_v[N].mp4`，微信版加 `_发微信用`
- 大改前先备份，主理人常要求“保留保底以便对比”
- **基准版写进 `PLAN_vN.md` 开头。** 主理人最满意的那版就是基准，不一定是最新版
- 内部编号不等于修改轮数。对外说实际轮数
- 主理人如果用手机重剪或配乐，那版另存为 `片名_发布版.mp4`

---

## 交付习惯

- **给本地文件。** 主理人打不开部分网页链接，文件才可靠
- 说明写白话，用“成片第几秒”定位
- 讲 AI 没法确认的地方，不要假装确认过
- 修改前先复述理解
- 上线和对外发布，先问

## 什么时候沉淀成 skill

同一类片子做第二次时，就该做。

已经沉淀的：

| Skill | 来源 | 用途 |
|---|---|---|
| `keynote-launch-film` | 连盈发布会片 | 企业发布会片 |
| `nobody-mv` | Nobody | 自拍变装 MV |
| `hely-motion-film` | hely 整片 | 白底产品展示片 |
| `huashu-art-motion` | 外部安装 | 艺术风格和解说动画 |

已有方法，但还没做成 skill：

| 方法 | 来源 | 现状 |
|---|---|---|
| 歌词踩点剪辑法 | jd 拉斯维加斯 | 有方法文档和脚本 |
| 动态语法六条 | hely 玻璃片 | 有方法文档和通用规格 |
| 倒放法、一张定场法 | MV1–MV3 | 只写在第 03 章 |
| 海报快闪 | QUIET HOURS | 有方案，来自开源项目 |
| 微缩世界动画 | 东莞国贸 | 有方案 |
