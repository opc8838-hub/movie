D. 故事盲审

新开一个 AI，只发这段和故事文本。

这是一支短片的逐镜头故事。你第一次看，只挑错，不改文件。
1. 先写出你看懂的故事
2. 这支片想说什么，能用一句话说出来吗
3. 开头 3 秒抓人吗
4. 每个转折合理吗？东西从哪来，现实里会这样吗
5. 哪些镜头 AI 容易拍错
6. 哪句话换个品牌也能用？那就是口号
每条写：镜头、问题、建议改法。没把握写“可能”。最后写“通过”或“不通过”。

E. 提交前审核

新开一个 AI。每条视频提交生成前都走一遍。

你是审核，只读不改。这个镜头马上要提交视频生成，花的是真钱。
材料：[提示词]、[首帧]、[尾帧]、[人物或道具参考]、[分镜]、[配色]
放大看图，逐项核对：
1. 提示词和图片对得上吗：位置、左右、颜色、人数、道具、衣服、表情
2. 首尾帧的机位、大小、背景一致吗？不该变的地方有没有变
3. 和前后镜头、禁用清单冲突吗
4. 动作现实吗？手放在哪？每个动作的原因写了吗
5. 模型可能在哪里出错：同时动作、凭空出现、脸变形、走反方向、歧义词
最后只写“通过”或“不通过”，不通过就逐条列出要改什么。

F. 视频提示词

七段结构【借鉴自 Eian】，每一秒发生什么都写下来。

【画风】[一句话]。整段的画风、颜色、人物和首尾帧完全一致。
【镜头】整段 [X] 秒，[景别]，[机位]，[运镜；不动就写“不推不拉不摇，不切镜”]。
【构图与配色】[人和东西在画面哪里，光和颜色是什么。和首帧对得上]
【人物】[长相、衣服、固定道具，写死]
【逐秒】
0–0.2 秒：完全静止，和首帧一样。
[每段：谁做什么，表情怎么变，手放在哪，往画面哪边]
最后 0.3 秒：所有人停住，和尾帧一致。
【声音】只有 [看得见原因的声音]。人物不说话。
【约束】画面里一直只有首帧这几个人和这些东西，脸和身形全程不变，一镜到底，没有文字、字幕、水印。

补充规矩：

  • 规则写死，风格放开。 不能错的写死（菜不能换、店名不能错）；好不好看交给参考图
  • 用 Codex 画图时，提示词写清“生成一张图、不要运行命令”，并让它把图复制到项目目录

H. 成片盲审

新开一个 AI，只给成片。

这是成片：[文件]。你第一次看，我不告诉你任何结论。
1. 解码，每个镜头取多张全尺寸帧，切点前后各取 3 帧
2. 先写你看懂的故事，再列看不懂的地方
3. 逐镜查：重复动作、物品数量变化、穿帮、跳帧、颜色跳变、脸变形、字错、水印、别家品牌
4. 明确写出你查不了的东西：动态手感、声音
每条写：时间、帧号、问题。分“硬伤”和“小问题”。

I. 执行者任务书

派给 Sonnet 或 Codex 时用。

背景：[一句话]
读：PLAN.md [版本]、handbook/05-tech.md
输入：[文件路径]　输出：[文件路径]

必须遵守：
- 只做这里写的。写死的数值不准改，觉得不对就停下来说
- 禁用清单（写完整路径）：[ ]
- 不准花钱：不调用付费视频，除非这里写明
- 素材不改色、不放大裁切

做完前：
- 先出静帧或小样，不要直接跑整片
- 按原尺寸放大检查
- 如实写已知问题。不写“完美”

交付格式：产出路径 / 怎么重渲 / 我检查了什么 / 没检查什么 / 已知问题

调用 Codex 时注意：超过 15 分钟没产出就重来；图常留在它自己的生成目录，要去捞。
